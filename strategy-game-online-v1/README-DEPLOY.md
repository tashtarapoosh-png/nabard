# راه‌اندازی نسخه آنلاین

این نسخه همان بازی `fixed25.html` است با یک لایه سرور برای نگهداری اطلاعات در PostgreSQL/Supabase.

## 1) Supabase
فایل `schema.sql` را در SQL Editor پروژه Supabase اجرا کنید.

## 2) Render
کل پوشه پروژه را در GitHub قرار دهید و آن را به یک Web Service در Render وصل کنید.

- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `DATABASE_URL`

مقدار `DATABASE_URL` را از Connection String دیتابیس Supabase بردارید. برای Render در صورت نیاز از Connection Pooler/Supavisor استفاده کنید.

## 3) رفتار ذخیره‌سازی
- نیروهای هر قلعه در SQL ذخیره می‌شوند.
- چینش دفاعی هر قلعه در SQL ذخیره می‌شود.
- حمله‌های در حال حرکت در SQL ذخیره می‌شوند و `finish_at` دارند.
- نبردها و اطلاعات `batman` در SQL ذخیره می‌شوند.
- اگر مرورگر یا بازیکن آفلاین شود، اطلاعات از بین نمی‌رود.
- وقتی سرور دوباره درخواست دریافت کند، حمله‌های زمان‌سررسیده پردازش می‌شوند؛ بنابراین وضعیت از زمان ذخیره‌شده در SQL ادامه پیدا می‌کند.

این نسخه هنوز ورود کاربر/حساب کاربری ندارد؛ طبق درخواست فعلی، هر کسی که لینک را باز کند صفحه انتخاب قلعه را می‌بیند.
